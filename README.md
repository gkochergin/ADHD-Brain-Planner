# Planner

A simple day, week and month planner built for how my ADHD brain works.

**Live demo:** https://YOUR-USERNAME.github.io/planner

## Features

- Day, week and month views
- Drag tasks from the sidebar onto the calendar
- Move and resize blocks by dragging
- Weekly repeating tasks
- Import tasks and save backups as JSON
- Keyboard shortcuts: ← → to move, `d` `w` `m` to switch views, `t` for today

## Usage

Open `index.html` in a browser. Your data is saved in your browser.

## Future Features

- Currently working on creating a server version which is usable on any device
- AI integration where it helps create a balanced schedule based on info on different goals
